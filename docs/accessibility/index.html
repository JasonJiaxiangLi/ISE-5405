Accessibility

This site is designed for keyboard, pointer, and touch use, with direct PDF downloads available as a fallback.

Viewer controls

All lecture commands are available as labeled buttons. The arrow keys move between pages; Home and End jump to the beginning and end. Press ? in a lecture for the complete shortcut guide. Dialogs keep keyboard focus while open and restore focus when closed.

PDF content

Lectures are displayed from instructor-authored PDFs rather than converted into semantic HTML. The viewer exposes a selectable PDF.js text layer where the source PDF provides extractable text, and each lecture includes a direct download link. Reading order, mathematical notation, alternative text, and screen-reader quality ultimately depend on the source PDF.

Annotations

Ink is an optional visual overlay. It has a programmatic label but its freehand contents are not translated into text. Color is not the only signal used for quiz feedback or tool state. Annotations can be exported to JSON for backup and transfer.

Motion, contrast, and touch

The design uses high-contrast text, visible focus indicators, large touch targets, and reduced animation when your operating system requests reduced motion. The presentation stage adapts to phones, tablets, desktops, and projectors.

Known limitations

  • Beamer overlays appear as separate PDF pages; they are not semantic element-level reveals.
  • Canvas-drawn annotations and laser movements are inherently visual.
  • Very long handouts may require additional time and memory before printing.
  • Browser fullscreen, printing, and local file selection can vary by browser and device.
